# Project instructions

## Session handoff

Save a `HANDOFF.md` at the repo root:

- at the end of every session,
- before any significant delay (stepping away, waiting on someone, pausing work), and
- as soon as you learn the 5-hour usage quota is above 90% (for example from a usage-limit warning). Don't wait to be asked.

Overwrite the previous file each time. Keep it short and include:

1. **Goal** – what we're building and the current objective.
2. **Done** – what was finished this session (commits by hash).
3. **In progress** – unfinished work and the exact state of the working tree (anything uncommitted or not pushed).
4. **Next steps** – ordered, concrete actions for the next session.
5. **Open questions / blockers** – decisions waiting on the user.
6. **Gotchas** – anything learned that the next session would otherwise have to rediscover.
